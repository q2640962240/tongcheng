# 白夜隐私政策

更新日期：2026年8月28日（v2 品牌升级版）

## 一、引言

白夜（以下简称"我们"）是一款面向成年人的同城社交与线上付费陪玩陪聊平台。我们深知个人信息对您的重要性，并会尽全力保护您的个人信息安全可靠。我们致力于维持您对我们的信任，恪守以下原则保护您的个人信息：权责一致、目的明确、选择同意、最少够用、确保安全、主体参与、公开透明等。

本版本在 v1 基础上补充了「动态广场 / 同城组局 / 红包签到 / 白夜精英会员」等新功能涉及的个人信息处理规则。

## 二、我们收集的信息

### 2.1 您主动提供的信息
- **手机号码**：用于注册、登录和身份验证
- **个人资料**：昵称、头像、性别、城市、个人简介
- **认证信息**：真实姓名、身份证号（仅用于实名认证 / 精英真人认证，加密存储，最小权限访问）
- **服务信息**：您发布的服务标题、描述、价格、封面图等
- **动态发布内容**：您在「发现-动态广场」发布的文本（≤500 字）、图片（≤9 张）、所选城市标签（详见 §2.4）
- **组局报名信息**：您在「发现-同城组局」创建或报名时提供的活动城市、活动时间、人数要求、报名留言（详见 §2.5）
- **举报与反馈信息**：您在「意见反馈-举报」通道提交的被举报对象 ID（动态 / 组局 / 用户）、举报描述、证据图片

### 2.2 自动收集的信息
- **设备信息**：设备型号、操作系统版本、唯一设备标识符
- **日志信息**：访问时间、访问页面、IP 地址
- **位置信息**（可选授权）：
  - 仅在使用「附近的人 / 同城组局优先匹配」时获取一次或多次粗略位置（GPS / 网络定位）
  - **不会**持续后台追踪位置；位置精度默认下采样到城市级
  - 您可随时在「设置 → 隐私 → 位置匹配开关」完全关闭位置匹配（详见 §6.3）

### 2.3 第三方获取的信息
- 微信/支付宝登录授权的基本信息
- 推送服务商（极光 / 个推）提供的设备标识符（仅用于离线推送）

### 2.4 动态发布相关信息（v2 新增）
- 您发布的动态文本和图片将进入内容安全审核通道：
  - 发布前：敏感词正则实时过滤（30+ 黑名单，白名单豁免「白夜」品牌词）
  - 发布后：进入「待审核」状态，管理员通过后台「动态管理」页面人工审核
  - 审核通过后对其他用户可见；被拒绝将以系统通知告知原因
- 动态默认展示您所选的**城市标签**（可在发布页选择「不展示城市」）
- 点赞 / 评论仅记录用户 ID 与时间戳，不附加额外个人信息

### 2.5 同城组局相关信息（v2 新增）
- 您创建组局时填写的活动城市、活动地点（仅展示**区级**精度，不暴露具体门牌号）、活动时间将公开给其他用户浏览
- 您报名组局时：
  - 组局发起人可见您的昵称和头像
  - 其他报名人仅可见头像墙与昵称首字（保护隐私）
  - 组局「已关闭」后 30 天自动归档，不再对外展示
- 组局人数进度条基于实际报名人数计算，不暴露单个报名人的实名信息

## 三、信息使用

### 3.1 服务提供
- 注册登录、身份验证
- 展示用户资料、服务信息
- 处理订单、支付（钻石 / 星币）、充值、提现
- 即时通讯（文本 / 语音消息，端到端 + 服务端敏感词扫描）
- **动态广场推荐**（v2 新增）：按发布时间、热度、城市标签排序
- **同城组局匹配**（v2 新增）：按位置（如已授权）、兴趣标签、组局进度排序推荐
- **红包签到**（v2 新增）：本地存储 + 服务端双重去重，仅记录签到日期用于奖励钻石发放
- **白夜精英会员**（v2 新增）：记录付费订单状态，用于解锁权益（组局优先展示 / 聊天守卫豁免 / 微信解锁查看等）

### 3.2 服务优化
- 分析使用数据，改进产品功能
- 排查服务故障，保障系统稳定
- A/B 测试新功能效果（匿名聚合统计，不关联到具体账号）

### 3.3 安全保障
- 防范欺诈、恶意行为
- 内容审核（敏感词过滤、图片鉴黄 / 暴恐 / 政治识别）
- 风险控制和身份验证（异常登录二次确认）
- **举报闭环**（v2 新增）：举报工单 → 管理员 24 小时内处理 → 处理结果站内通知 + 钻石奖励（如举报属实）

## 四、信息存储

- **存储地点**：中华人民共和国境内（默认本地 JSON 存储；生产可切换 OSS / MySQL，均需国内节点）
- **存储期限**：
  - 账号存续期间 + 注销后 30 天冷静期
  - 动态 / 组局 / 评论：账号存续期间保留；账号注销后 30 天匿名化处理
  - 举报工单：保留 180 天（满足监管追溯要求）
  - 敏感词过滤日志：保留 30 天（仅记录命中词与接口路径，不含完整原文）
- **加密措施**：密码 bcrypt 加密、JWT 鉴权、HTTPS 传输加密、身份认证照片文件级 AES-256 加密
- **存储方式**：JSON 文件加密存储 + 文件系统（生产可替换为 MySQL + OSS）

## 五、信息共享

我们仅在以下情形共享您的信息：

1. **获得您的明确同意**（例如：组局报名后同意发起人查看您的联系方式）
2. **支付服务**：与微信支付 / 支付宝共享订单信息（完成支付必需，不含敏感个人信息）
3. **推送服务**：与极光 / 个推共享设备标识符（发送推送必需，不含实名信息）
4. **短信服务**：与阿里云 / 腾讯云共享手机号（发送验证码必需，仅传递手机号）
5. **内容安全第三方**（v2 新增）：如接入图片 / 文本审核云服务（可选），仅传递待审核内容，不附带账号实名
6. **法律要求**：根据法律法规或政府机关的合法要求（含法院传票、公安协查函等）

> **我们不会向任何第三方出售您的个人信息。** 白夜精英会员数据仅用于平台内部权益判定，不对外共享。

## 六、您的权利

### 6.1 基本权利
- **查询权**：随时查看您的个人信息、钱包流水、订单、发布的动态 / 组局
- **更正权**：修改昵称、头像、性别、城市、个人简介
- **删除权**：
  - 注销账号（30 天冷静期后永久删除，期间可撤销）
  - 删除自己发布的单条动态 / 单个组局（立即不可见，30 天后物理删除）
- **撤回同意**：关闭短信免打扰、关闭推送、关闭位置匹配
- **数据导出**：可联系客服导出您的个人数据（JSON 格式，≤ 7 个工作日交付）

### 6.2 动态与组局专属权利（v2 新增）
- **撤回发布**：已发布的动态 / 组局可随时在「我的发布」中删除或设为私密
- **退出组局**：报名后可在组局详情页「取消报名」，发起人将不再看到您的报名信息
- **关闭城市展示**：发布动态时可勾选「不展示我的城市」

### 6.3 位置信息关闭方法（v2 新增）
位置匹配功能默认**关闭**，首次使用「附近 / 同城优先」时才会弹窗授权。关闭步骤：

1. 打开「白夜」App → 底部 TabBar「我的」
2. 进入「设置」→「隐私与通知」
3. 关闭「允许同城匹配使用我的位置」开关
4. （系统级）iOS：设置 → 隐私与安全性 → 定位服务 → 白夜 → 永不；Android：设置 → 应用 → 白夜 → 权限 → 位置 → 拒绝

关闭后：同城组局 / 动态仍可使用，但不会优先展示附近内容，推荐列表退化为按时间排序。

## 七、未成年人保护

- 本应用面向 18 岁及以上成年人，不向未成年人提供服务
- 未成年人不得注册使用；注册时通过身份证号 + 年龄校验拦截
- 如发现未成年人冒用成年人身份注册，我们将立即注销其账号并删除所有关联内容
- 涉及未成年人的动态 / 组局 / 聊天内容一经发现，立即下架并永久封禁发布账号
- 家长如发现未成年人使用，可通过客服通道联系我们快速处置（24 小时响应）

## 八、安全措施

- HTTPS 全站加密传输（TLS 1.2+）
- 密码 bcrypt 哈希存储（cost=12）
- JWT 双 Token 鉴权（access 2h + refresh 30d，支持单设备登出）
- API 限流防刷（短信：IP 1/min 10/h；全局：1000/min per IP）
- XSS / SQL 注入防护（输入过滤 + 参数化查询模拟）
- 敏感信息日志脱敏（手机号中间 4 位打码、身份证仅留前后 2 位、支付流水号截断）
- 内容安全（v2 新增）：
  - 敏感词正则 30+ 条（动态 / 评论 / 组局标题 / 反馈文本）
  - 图片上传走内容审核通道（生产可接入阿里云 / 腾讯云图像安全）
  - 举报通道闭环 + 管理员 24 小时处理 SLA
  - 敏感词命中日志（保留 30 天，仅审计用，不展示给普通用户）
- 定期安全审计（每月一次内部审计；每年一次第三方渗透测试）

## 九、变更通知

本政策可能更新，更新后我们将：
1. 在「我的 → 设置 → 关于 → 隐私政策」页面标注最新更新日期
2. 重大变更（例如新增信息收集类型）通过应用内弹窗或推送通知
3. 继续使用即视为同意更新后的政策；如不同意，可注销账号停止使用
